pyminleon¶

pyminleon: asyncio control of Minleon NDB-Pro LED controllers' built-in effects over HTTP.

pyminleon.exceptions¶

pyminleon exception hierarchy.

MinleonError Objects¶

class MinleonError(Exception)

Base class for every pyminleon error.

ConfigError Objects¶

class ConfigError(MinleonError, ValueError)

Invalid host, port, timeout, or call argument.

ControllerError Objects¶

class ControllerError(MinleonError)

A controller could not be reached, timed out, answered with a non-200 status, or sent something unusable.

pyminleon.ndb¶

Control of the Minleon NDB-Pro over the HTTP endpoints its own web UI uses.

It selects the controller's built-in effects, sets their intensity, and recalls stored show presets; it never writes the controller's saved settings (no saveon, no preset Set, no ?s=N). The controller exposes its effect state only as HTML, so state and presets read the UI pages with strict regexes and raise ControllerError when the markup is not what firmware 2.0 serves. config and status return the raw JSON documents from /api/config and /api/status. Stdlib only.

DDP pixel data overrides the built-in effect while it flows; about 20 s after DDP stops the controller falls back to it.

NDBController Objects¶

class NDBController()

Selects and reads the built-in effects of a Minleon NDB-Pro over plain HTTP.

Every call is one or two short HTTP/1.0 requests bounded by timeout each. ControllerError means the controller could not be reached, timed out, answered with a status other than 200, or answered with a page or document pyminleon cannot read.

identify¶

async def identify(host: str,
                   *,
                   port: int = 80,
                   timeout: float = 3.0) -> str | None

The supported model id (e.g. "NDBPRO") at host, or None.

None means the host did not answer in time, did not answer GET /api/status with a JSON status, or reports a model not in SUPPORTED_MODELS. ConfigError for a bad host, port, or timeout.

pyminleon._http¶

A minimal asyncio HTTP/1.0 client for talking to Minleon controllers on the LAN. Private; stdlib only.

One asyncio.timeout bounds connect, request, head, and body together, so a server dripping one byte at a time cannot stall a caller. Head and body are size-capped, redirects are never followed, and the host is validated so it can never steer the path, port, or scheme.

host as it goes in a URL: a hostname or IPv4 address as is, an IPv6 literal bracketed.

url¶

def url(host: str, port: int, path: str) -> str

http://HOST:PORT/PATH; host must be a hostname, IPv4 address, or IPv6 literal (brackets optional).

request¶

async def request(host: str,
                  port: int,
                  path: str,
                  *,
                  timeout: float,
                  method: str = "GET",
                  body: bytes | None = None) -> Response

One HTTP/1.0 exchange under one deadline. Redirects are never followed.

Raises ConfigError for a bad host or path, ControllerError for a body over MAX_BODY, and one of TRANSPORT_ERRORS when the exchange fails or the deadline passes.
